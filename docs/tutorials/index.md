# Tutorials

Step-by-step lessons that take you from a clean checkout to a working Kestrel wireless connection.

---

## Learning Path

| Tutorial | What you will accomplish | Prerequisites |
| :--- | :--- | :--- |
| [Getting Started](getting-started.md) | Build Kestrel, verify your host in the unprivileged e2e lab, install system files, switch onto `systemd-networkd` + an L2 backend, and join your first Wi-Fi network. | Rust 1.89+, `systemd-networkd`, `systemd-resolved`, `systemd-creds`, D-Bus, polkit, and either `wpa_supplicant` or `iwd` |

Looking for a specific task after setup? Continue to [How-To Guides](../how-to/index.md) or browse the full [CLI & Daemon Reference](../reference/commands.md).
